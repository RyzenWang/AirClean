# AirClean 0.4 Issue 列表（设置与常驻）

> 目标版本：0.4.0。来源：[GAP-ANALYSIS.md](GAP-ANALYSIS.md) §9 的 0.4 里程碑。
> 估时口径同 0.3：S ≤ 0.5 天、M ≤ 2 天、L > 2 天。

## 0. 里程碑定义

**主题**：让清理可以配置，也让应用可以安静地待在后台。

**范围**：

- 删除失败保护：失败率过高自动中止、磁盘满识别、完成页说明；
- 设置模型 v2 与迁移；
- 设置窗口：外观、扫描范围、排除项、阈值、更新、托盘、提醒；
- 快速扫描 / 全盘扫描；
- 排除项在扫描与删除两侧生效；
- 阈值可配（大文件、重复文件、哈希预算）；
- 托盘图标、关闭/最小化到托盘；
- 定时提醒（默认关闭）与登录自启；
- 文档、截图、三平台验收。

**出口标准**：

- [ ] 设置重启后保留，旧 v1 设置自动迁移；
- [ ] 快速扫描只跑缓存、日志、废纸篓；全盘额外跑大文件与重复；
- [ ] 排除目录不会被扫描、也不会被删除；
- [ ] 阈值改动在下次扫描生效；
- [ ] 托盘可恢复窗口，关闭到托盘不丢状态；
- [ ] 提醒默认关闭、不自动删除；
- [ ] 三平台 CI 绿，新增测试 ≥ 25；
- [ ] README / DESIGN / VERIFICATION-0.4 更新。

## 2. 详细 Issue

### AC-403 设置窗口

**背景**
当前设置只是顶栏 `MenuFlyout`（主题、语言、管理员开关），新增的 `AppSettings` 字段
没有入口。

**设计**
- 新增 `Views/SettingsWindow.axaml`（独立窗口，`ShowDialog` 或非模态；建议模态 720×620）。
- 分区：外观（主题/语言）、扫描（快速/全盘、排除项、阈值）、更新、托盘与提醒。
- VM 直接绑定 `AppSettings` 的副本，点“保存”后写回并关闭；取消不落盘。
- 排除项列表：添加目录按钮走 `StorageProvider.OpenFolderPickerAsync`，可删除。
- 阈值用 `NumericUpDown`，保存时 clamp。
- 顶栏齿轮改为打开窗口（保留 flyout 快捷主题/语言可后续简化）。

**验收**
- 修改主题/语言/扫描范围/阈值/排除项，保存后立即生效并在重启后保留；
- 取消不会改动任何设置；
- 920×620 下窗口不溢出，浅色/深色都正常。

**估时**：3–4 天 · `area:app`

### AC-404 快速 / 全盘扫描

**背景**
当前每次扫描都包含大文件与重复文件；数据盘全盘遍历可能几分钟。DESIGN 2.3 的
“默认快速扫描”没有实现。

**设计**
- `VolumeScanRequest` 已有 `IncludeLargeFiles` / `IncludeDuplicates` / `IncludeCaches`。
- 系统盘：`ScanMode=Quick` → caches + trash；`Full` → 再加 large files + duplicates。
- 数据盘：快速模式至少保留 large files（否则只剩废纸篓，价值太低），全盘再加 duplicates；
  在设置页文案里说明。
- 当前 trash 由 `LargeFileScanner` 附带返回；快速模式需在 `VolumeScanService` 里单独
  探测废纸篓，避免“快速扫描不含废纸篓”。
- 欢迎页/结果页显示当前范围（已有 `ScanScopeText`，补充“快速/全盘”）。

**验收**
- 快速扫描的分类只有缓存、日志、废纸篓；
- 全盘扫描额外出现大文件与重复文件；
- 切换设置后下一次扫描生效。

**估时**：2 天 · `area:core` `area:app`

### AC-405 排除项

**背景**
用户无法“别动这个目录”，只能每次取消勾选。

**设计**
- `PathExclusions.IsExcluded(exclusions, path)`：规范化、大小写按平台、子路径匹配。
- 扫描器接受排除列表：`Scanner`、`LargeFileScanner`、`DuplicateScanner` 在遍历前
  跳过排除目录，避免白扫。
- 删除侧：`DeletionService` 注入 `Func<string,bool> isExcluded`，命中则跳过并记
  `SkipReason.Excluded`。
- 设置窗口维护列表；结果页不显示被排除项。

**验收**
- 排除目录下的文件不出现在任何分类；
- 即使手工构造条目，删除也会拒绝并说明；
- 排除项持久化、重启保留。

**估时**：2 天 · `area:core` `area:app`

### AC-406 阈值可配

**背景**
大文件阈值/上限、重复文件最小体积/组上限、哈希预算全部硬编码。

**设计**
- `LargeFileScanner` 接受阈值与 `MaxItems`；`DuplicateScanner` 接受最小体积、组上限。
- VM 从 `AppSettings` 读取，替换 `LargeFileScanner.DefaultThresholdBytes` 与
  数据盘 2 GB 硬编码。
- 结果页文案使用实际阈值（不再写死 100 MB / 200）。

**验收**
- 改阈值后扫描结果变化；
- 非法值被归一化（设置层已处理）；
- 现有测试改用显式参数。

**估时**：1 天 · `area:core` `area:app`

### AC-407 托盘与关闭到托盘

**背景**
关闭窗口即退出，无法后台常驻。

**设计**
- `TrayIconService`：可选创建，失败只记日志不影响启动（Linux 无 StatusNotifier 时）。
- 菜单：显示窗口、快速扫描、退出。
- 设置项 `CloseToTray` / `MinimizeToTray`；默认关闭，保持现有“关闭即退出”行为。
- 单实例唤醒复用现有信号文件。

**验收**
- 开启关闭到托盘后，关闭窗口进程仍在，托盘可恢复；
- 退出菜单真正退出；
- 未开启时行为不变。

**估时**：2 天 · `area:app`

### AC-408 定时提醒与登录自启

**背景**
路线图中的“定时提醒”未开始；默认关闭、不自动删除。

**设计**
- 设置：`ReminderEnabled`、`ReminderIntervalDays`、`LastReminderAt`、`RunAtLogin`。
- 启动时与每 6 小时检查一次；到期后在状态栏/托盘提示，不自动扫描或删除。
- 登录自启：Windows 注册表 `Run`；macOS `LaunchAgent`；Linux XDG autostart；
  关闭时删除对应项，失败要提示。
- 托盘未启用时提醒只写状态栏与欢迎页提示。

**验收**
- 默认关闭时无任何提示；
- 到期只提示，不删除；
- 自启开关在三平台写入/移除正确（至少 Windows 本机验证）。

**估时**：2 天 · `area:app` `area:platform`
