## 已知限制（0.4）

- 托盘依赖桌面环境；Linux 无 StatusNotifier 时没有图标，应用仍可用。
- 提醒只写状态栏和托盘 tooltip，不使用系统通知中心。
- 关闭到托盘会拦截窗口关闭；系统注销/关机时的行为尚未在真机确认。
- Windows 自启用 `reg.exe`，非英文系统的删除错误文案未覆盖；失败会在设置页显示。
- 快速模式在数据盘仍扫描大文件；全盘才包含重复文件。
- 重复文件哈希预算现在统一取设置值（默认 8 GB），不再单独给数据盘 2 GB。

## 结论

0.4 的自动化覆盖了设置、扫描范围、排除项、阈值、删除保护、提醒间隔和自启文件内容；
托盘、真实设置窗口、真实自启与提醒到点提示仍需要一次桌面手测。推送后应补跑三平台 CI。
